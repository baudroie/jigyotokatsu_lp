# baudroie NEXT LEADER 採用LP

## 起動方法

`index.html` を直接ブラウザで開くか、このフォルダで静的HTTPサーバーを起動してください。

```sh
python3 -m http.server 4173
```

## 使用アセット

元フォルダの画像は変更せず、実装用に `assets/` へコピーして英数字名へ整理しています。対応関係は `asset-map.json` を参照してください。Hero、3つの訴求カード、黒背景図解、フィールド、キャリア、先輩、選考フロー、最終CTAの提供画像を使用しています。

## LINE URL

`script.js` 先頭の `LINE_URL` を実URLへ変更してください。現在は未設定のため `#` です。

## ブレークポイント

- PC: 1024px以上
- Tablet: 768〜1023px
- SP: 767px以下

## 主要セクション

Hero / 3つの訴求カード / なぜ最前線で働けるのか / あなたに任されるフィールド（PCのみ） / NEXT LEADERのキャリアパス / 先輩事例 / 選考フロー / 最終CTA / Footer
