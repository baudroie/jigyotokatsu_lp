# baudroie NEXT LEADER 採用LP

## 起動方法

`index.html` を直接ブラウザで開くか、このフォルダで静的HTTPサーバーを起動してください。

```sh
python3 -m http.server 4173
```

## 使用アセット

元フォルダの画像は変更せず、実装用に `assets/` へコピーして英数字名へ整理しています。対応関係は `asset-map.json` を参照してください。Hero、3つの訴求カード、黒背景図解、フィールド、キャリア、先輩、選考フロー、最終CTAの提供画像を使用しています。

## LINE URL

`script.js` 先頭の `LINE_URL` を実URLへ変更してください。現在は未設定のため `#` です。

## ブレークポイント

- PC: 1024px以上
- Tablet: 768〜1023px
- SP: 767px以下

## 主要セクション

Hero / 3つの訴求カード / なぜ最前線で働けるのか / あなたに任されるフィールド（PCのみ） / NEXT LEADERのキャリアパス / 先輩事例 / 選考フロー / 最終CTA / Footer

キャリア・人物・タイトル・CTAは自然比率の全画像表示です。透明なcanvasの余白だけをレイアウト上相殺し、overflowやマスクで隠していません。Careerの非操作画像は透明部分がCTAのクリックを奪わないようpointer-eventsを無効にしています。

### 未完了の制約

- 3つの訴求カードは見出しと3枚が一体になったPNGしかありません。既存の部分表示を完全に撤去しつつ縦3段にするには、個別PNGの追加または素材抽出の許可が必要です。現在はカード本体・文字・イラスト・下枠を含む範囲を表示し、CSSの二重カードは撤去済みですが、PNG全体表示の条件は未達です。
- 提供キャリアPNG内の完成カードはSP正解より縦長です。説明文・人物・年収を全表示し、読める幅を維持するとSPキャリアはお手本より約357px長くなります。画像を歪めたり本文を切ったりして差を隠していません。
- このため現在の総合QAはblockedであり、「お手本と完全一致して完了」とは判定していません。
